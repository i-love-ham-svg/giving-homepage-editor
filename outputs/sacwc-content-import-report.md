# 송악사회복지관 공식 콘텐츠 반영 보고서

기준 사이트: https://www.sacwc.kr/  
점검일: 2026-08-04

## 현재 반영 완료

- 공식 공지 상위 10개: 상세 본문, 표, 공개 이미지, 첨부파일 다운로드, 하이퍼링크 유지
- 시설현황: 건립년도·부지·연면적·운영시간과 외부·3층·2층·1층·지하 시설 카드 반영
- 시설 층별 배치: 공식 공개 표를 층별 배치 표와 시설별 개소·면적 표로 재구성
- 조직도: 공식 조직도에 공개된 15개 직책·담당업무 반영, 공개 확인 가능한 김형철 관장 실명 반영
- 프로그램 시간표: 공식 3월 기준 원본 이미지 로컬 저장, 요일·시간별 프로그램 카드 15개 반영
- 운영법인 소개: 현 운영법인 `(재)송악읍개발위원회`와 당진시 수탁 운영 사실을 공개자료 기준 4개 카드로 구성
- 공식 영상: 공식 영상 6편의 유튜브 썸네일, 원본 재생 링크, 공식 게시글 링크 연결
- 방문자 자유게시판: 공개 목록 상위 10개 제목·등록일·답변 구분 반영, 개인 작성자 이름은 `방문자`로 비식별화
- 언론보도: 최근 공개 언론보도 8건과 공식 원문 링크 유지
- 메뉴 연결: 복지관 소개·사업 안내·알림마당 하위 메뉴에 신규 섹션 7개 연결
- 편집 진행률: 납품 진행률과 별도로 상단에 큰 빨간 표시 추가

## 공개 제한으로 반영하지 않은 내용

- 직원 실명 전체: 공식 조직도에서 자동 보호 처리되어 공개 확인 가능한 관장 외 실명은 우회 추출하지 않음
- 방문자 자유게시판 상세 본문: 공식 사이트 로그인 정책으로 보호되어 제목·날짜 외 본문은 복제하지 않음
- 방문자 전화번호·이메일·실명: 개인정보 보호를 위해 새 페이지에 복제하지 않음
- 법인소개 전체 원문: 공식 사이트에 별도 법인소개 전문이 없어 당진시 공개자료와 공개 보도 기준 요약만 반영
- 시설 도면 원본: 공식 시설현황은 도면이 아닌 표로 공개되어 있으며, 배경용 PNG는 내용 없는 장식 이미지라 사용하지 않음
- 영상 원본 파일: 저작권과 조회 기록을 유지하도록 파일 다운로드 대신 공식 유튜브 원본 재생 링크 사용
- 언론기사 전문: 언론사 저작권 보호를 위해 제목·날짜·원문 링크만 반영
