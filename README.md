# 송악사회복지관 홈페이지 편집기

송악사회복지관 담당자가 기관 소개, 공지·소식, 사업, 일정표, 시설현황, 조직도, 자원봉사, 후원, 갤러리, 인사말, 찾아오시는 길과 하단 기관정보를 화면에서 직접 수정할 수 있는 납품용 편집 프로젝트입니다.

## 실행

1. 프로젝트 폴더의 `open-editor.cmd`를 더블클릭합니다.
2. 브라우저에서 편집 화면이 열리면 상단의 **편집 / 미리보기**를 이용합니다.
3. PC, 소형폰, 휴대폰, 태블릿 화면을 각각 확인합니다.

직접 접속할 때는 로컬 서버 실행 후 아래 주소를 사용합니다.

<http://127.0.0.1:43185/representative-greeting-editor.html>

소통게시판:

<http://127.0.0.1:43185/community-board.html>

편집기 상단의 **게시판** 버튼으로도 새 창에서 열 수 있습니다.

## 소통게시판

- 복지관 공식 소식과 주민 이야기·질문·제안을 분리합니다.
- 주민 게시글은 수정·삭제 비밀번호를 사용하며 관리자 승인 후 공개됩니다.
- 사진과 영상은 합쳐서 12개까지 첨부할 수 있고 대표 썸네일을 선택할 수 있습니다.
- 검색, 분류, 최신순·조회순, 공유, 신고, 임시저장을 지원합니다.
- 로컬 점검용 관리자 비밀번호는 `songak-local-admin`입니다.
- 실제 배포에서는 `BOARD_ADMIN_PASSWORD`를 별도 비밀번호로 설정하고 게시글 데이터와 미디어 폴더를 공용 데이터베이스·파일 저장소에 연결해야 합니다.

## 저장과 백업

- **저장**: 현재 브라우저에 편집 상태를 저장합니다.
- **백업**: 현재 작업을 날짜가 포함된 JSON 파일로 내려받습니다.
- **복원**: 백업 JSON 파일을 선택해 저장 당시 상태로 되돌립니다.

브라우저 데이터가 삭제되거나 다른 PC에서 작업할 수 있으므로, 중요한 수정 후에는 반드시 **저장**과 **백업**을 함께 실행하세요.

## 기본 반영 자료

2026-08-03 기준 [송악사회복지관 공식 홈페이지](https://www.sacwc.kr/)의 공개 자료를 기준으로 다음 항목을 반영했습니다.

- 기관명, 미션, 비전 방향과 슬로건
- 공식 인사말
- 사례관리 절차
- 주요 서비스제공 프로그램
- 후원 종류, 문의처와 계좌 안내
- 주요 연혁
- 최근 복지관 활동 제목
- 시설현황, 조직도와 자원봉사 참여 절차
- 공지·소식, 프로그램 일정표와 홈페이지 하단 정보
- 주소, 전화, 팩스와 이메일은 공식 홈페이지 기준으로 문서화

공지, 모집 일정, 프로그램 운영시간과 후원 정보는 변동될 수 있으므로 최종 배포 전 담당자의 확인이 필요합니다.

## 납품 전 확인

- 기관 로고와 대표 사진 등 사용 승인된 원본 이미지 등록
- 인사말 서명 주체와 최신 직책 확인
- 프로그램 일정·이용료·모집 상태 확인
- 후원 계좌와 담당 부서 확인
- 개인정보처리방침 및 신청 양식 연결 방식 확인
- PC와 모바일 미리보기 확인
- 최종 백업 파일 별도 보관

## 품질 점검

로컬 관리자·저장소·반응형 편집 회귀 검사는 `tools/test-all.mjs`에 모여 있습니다. 브라우저 전체 동작 점검은 `tools/README.md`의 항목별 테스트를 참고하세요.
