# 수정 이력 분류 및 운영 규칙

송악사회복지관 홈페이지의 수정 이력은 [`change-registry.json`](./change-registry.json)을 단일 원본으로 관리합니다. 이 문서는 분류 방법과 작업 순서를 설명하며, 개별 수정의 현재 상태를 따로 복사해 적지 않습니다.

## 왜 여러 축으로 분류하는가

`기능`이나 `섹션` 하나만으로 기록하면 공통 메뉴 수정이 소통게시판 또는 모바일에서 누락될 수 있습니다. 따라서 한 수정은 다음 정보를 동시에 가집니다.

| 축 | 예시 | 용도 |
|---|---|---|
| 주분류 | 기능, 버그, 디자인, 콘텐츠, 구조, 배포 | 작업 성격 |
| 기능 taxonomy | `layout.navigation.active-state` | 재사용할 기능 계약 |
| 화면 | 공개 홈페이지, 소통게시판, 편집기, 모바일 보기 | 적용 대상 |
| 경로·섹션 | 모든 메뉴 경로, 공통 내비게이션 | 실제 영향 범위 |
| 화면 크기 | PC, 태블릿, 모바일, 소형폰 | 반응형 누락 방지 |
| 사용자 역할 | 방문자, 복지관 담당자, 제작자 | 권한별 회귀 방지 |
| 상태 | 승인, 구현, QA, 배포 | 로컬 완료와 공개 배포 구분 |

## 한 수정에 반드시 기록하는 것

1. 사용자가 발견한 증거와 요청일
2. 확인된 근본 원인
3. 다시 깨지면 안 되는 불변조건
4. 단일 원본과 실제 수정 파일
5. 자동검사 및 실제 화면 검토 범위
6. 회귀 위험과 선행 작업
7. 공개 배포 승인 여부

## 표준 작업 순서

1. 요청을 레지스트리에 등록합니다.
2. 적용 범위와 불변조건을 먼저 확정합니다.
3. 단일 원본에서 수정하고 중복 구현을 만들지 않습니다.
4. 집중 자동검사를 통과시킵니다.
5. 원본·동기화본·빌드 산출물 일치 여부를 검사합니다.
6. PC·태블릿·모바일·소형폰 실제 화면을 확인합니다.
7. 사용자 승인과 공개 배포 승인을 각각 기록합니다.

## 완료 판정

- `verified`는 통과한 자동검사가 하나 이상 있어야 합니다.
- `full-pass`는 레지스트리에 기록한 모든 화면·역할 범위를 확인해야 합니다.
- 공개 주소 반영은 `publicDeployApproved=true`일 때만 가능합니다.
- 배포 전 로컬 수정은 항상 `local-only`로 남깁니다.

## 현재 우선 기록

- `NAV-ACTIVE-CONTRAST-001`: 선택한 페이지의 상위 메뉴가 다시 흰색으로 돌아오지 않도록 고정
- `NAV-CONTEXT-TRAIL-001`: 공통 메뉴 데이터에서 현재 위치를 파생해 모든 공개 페이지에 한 번만 표시
- `CTA-MAIN-INTERACTION-001`: 메인 소개 CTA의 실제 HTTP 이동·44px 터치·무겹침을 4개 화면 크기로 고정
- `BOOT-PUBLIC-SCOPE-001`: 공개 scope prefetch를 한 번만 소비하고 응답 유형별 fallback 요청 수와 복구 결과를 고정
- `PERF-PROGRAM-RENDER-001`: 공개 프로그램 카드만 지연 페인트하고 편집 데이터·마지막 카드 도달을 보존
- `CTA-DONATION-GATE-001`: 후원 CTA의 HTTP href·문구·44px·5개 카드 보존을 release gate에 포함
- `QA-PUBLIC-MATRIX-001`: 방문자 26개 공개 경로를 5개 실제 화면 크기, 총 130화면으로 검증
- `QA-STAFF-EDITOR-001`: 담당자 편집기·소통게시판 편집 surface·실제 운영 화면의 기능과 반응형 검증

## 공개 배포 전 후속 후보

- `EDITOR-EMBEDDED-ACTION-001`: 시각 프리뷰에서 실행하지 않는 운영 버튼을 명시적으로 비활성화하고 실제 운영 경로 안내
- `EDITOR-MOBILE-OVERLAY-001`: 320px 편집기에서 편집막대와 배경·장식 플로팅 컨트롤의 점유 높이 공유

후속 후보는 `proposed / planned / pending`으로 분리해 완료 항목과 섞지 않습니다. 현재 정책은 `publicDeploymentAllowed=false`이며 모든 레코드의 공개 배포 승인은 `false`입니다.
