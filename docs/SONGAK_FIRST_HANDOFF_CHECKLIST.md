## 3. 운영 환경변수와 Secret

운영값은 배포 서비스의 Secret 저장소에만 등록하고 Git, 문서, 채팅, 화면 녹화에 값을 노출하지 않습니다.

| 이름 | 용도 | 배포 전 조치 |
|---|---|---|
| `TEMP_EDITOR_ID` | 임시 담당자 로그인 ID | 기관 전달 계정 확정, 담당자 변경 시 교체 |
| `TEMP_EDITOR_PASSWORD` | 임시 담당자 로그인 비밀번호 | 충분히 긴 임의 문자열로 등록, 테스트 전달 후 회전 일정 확정 |
| `BOARD_SESSION_SECRET` | 담당자 세션 HMAC 서명 | 최소 32자 이상의 별도 임의값으로 등록 |
| `BOARD_HASH_PEPPER` | 게시글·요청자 파생 해시 보호 | 세션 Secret과 다른 별도 임의값으로 등록 |
| `APPLICATION_HASH_PEPPER` | 온라인 신청 요청자 파생 해시 보호 | `BOARD_HASH_PEPPER`와 분리한 별도 임의값 권장 |
| `BOARD_EDITOR_EMAILS` | 플랫폼 인증 담당자 이메일 허용 목록 | 사용할 경우 기관 공식 계정만 쉼표로 등록하고 퇴사·변경 절차 확정 |

배포 검증 명령에서만 사용하는 비밀값이 아닌 변수:

- `SONGAK_SITE_URL`
- `SONGAK_SITE_DOCUMENT_KEY` (기본값 `songak-homepage`)
- `SONGAK_HOSTING_MANIFEST`
